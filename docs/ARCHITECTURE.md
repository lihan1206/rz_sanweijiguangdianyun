## 2. 数据流图

### 2.1 点云上传流程
```
用户 → 前端 → Nginx → FastAPI → 文件存储
                    ↓
                  MySQL (元数据)
```

### 2.2 点云处理流程
```
用户 → 创建任务 → 任务队列 → Open3D处理 → 结果存储
                ↓                        ↓
              MySQL                   MySQL (结果记录)
```

### 2.3 协同场景流程
```
用户A ──┐
        ├──→ WebSocket连接 ──→ 场景同步 ──→ 广播更新
用户B ──┘         ↑                    ↓
                  └────── 消息分发 ←───┘
```

## 3. 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | React 18 + TypeScript | 响应式UI框架 |
| 渲染 | Three.js | WebGL 3D渲染 |
| UI库 | Ant Design 5 | 企业级UI组件 |
| 后端 | FastAPI | 高性能异步框架 |
| 点云处理 | Open3D | 点云算法库 |
| 数据库 | MySQL 8.0 | 关系型数据库 |
| 缓存 | Redis | 会话与热点缓存 |
| 容器 | Docker | 容器化部署 |
| 编排 | Docker Compose | 多容器编排 |
